# Detector de transparencia PNG
Comprueba todos los archivos `.png` de la carpeta e indica si usan transparencia o no.

## Instalación
```bash
pip install -r requirements.txt
```

## Uso
1. Coloca los archivos `.png` en la misma carpeta que `alpha-png.py`.
2. Ejecuta:

```bash
python alpha-png.py
```

El programa mostrará qué imágenes usan transparencia y cuales no.
